# TFE
Ce projet de fin d'études consiste à réaliser un pid adaptatif sous le thème : Optimisation de la Régulation d’un Convertisseur Buck par un Contrôleur PID Auto-Adaptatif Basé sur Extreme Learning Machine (ELM) : Étude Théorique, Implémentation sous Simulink et Perspectives Améliorées. Avec une étude comparative face à Fizzy PID, PINN PID et PSO PID
