PSO-PID : REGLAGE HORS LIGNE DU PID CLASSIQUE PAR ESSAIM DE PARTICULES
(7 octobre 2026)
=====================================================================

DOSSIER COMPLET ET AUTONOME : il contient la base commune v2.1 (modele
Buck_Commun.slx, tes trois modeles de base, essais, banc Python) et tout le
PSO-PID. Dezippe-le dans un dossier vide, fais de ce dossier le dossier
courant MATLAB, et lance les etapes ci-dessous. Ne garde pas les dossiers
ELM, PINN ou FUZZY sur le chemin MATLAB en meme temps (memes noms de
fichiers de base). Tout ancien dossier PSO ne sert plus.

A LIRE D'ABORD : criteres_pso_pid.txt
  Cadre, article de reference, modifications M1 a M3 avec leurs
  references, ecarts declares, previsions ecrites avant la recherche,
  resultats et bibliographie complete.

LA METHODE EN BREF
- Essaim de Gaing (IEEE Trans. Energy Conversion, 2004) : 50 particules,
  100 iterations, inertie de 0.9 a 0.4, c1 = c2 = 2, Vmax = moitie de la
  plage, gains cherches dans [0 ; 4] fois Ziegler-Nichols.
- M1 : cout = IAE sur quatre essais de reglage avec perturbations de
  charge, de Vin, de consigne et du bruit (E1 a E4, aucun n'est un des onze
  essais), rapportee a Ziegler-Nichols, demarrage pese 3/13 (Gaing eq. 6 ;
  Astrom, Panagopoulos, Hagglund 1998 et 2002 ; Krohling, Rey 2001 ;
  Alipoor 2009).
- M2 : contraintes (marge >= 30 degres, coupure <= fs/10 aux 12 coins)
  traitees par les regles de faisabilite de Deb (2000), comme Toscano
  Pulido et Coello Coello (2004).
- M3 : reglage avec les conditions initiales du bloc (0.5 et 0.01).
- Le PID est TON bloc "PID Controller" de Ziegler-Nichols ; seuls P, I, D
  changent, et restent fixes ensuite.

ORDRE D'EXECUTION
-----------------
0. (facultatif) python verifier_modele_commun.py
1. (deja fait) python recherche_pso_pid.py
   RECALCULER = False : reprend recherche_pso_pid.json et recalcule le cout
   de chaque gbest pour controle (quelques secondes). RECALCULER = True :
   refait les cinq recherches (35 a 70 minutes).
2. (deja fait) python banc_pso_pid.py
   Une minute. Sortie attendue : banc_pso_pid_sortie_console.txt.
3. MATLAB : Construction_PSO_PID
   Copie Buck_Commun.slx en Buck_Commun_PSO_PID.slx et y ecrit P, I, D.
4. python verifier_pso_pid.py
   Fin attendue : "RESULTAT : Buck_Commun_PSO_PID.slx est conforme."
5. MATLAB : Simuler_PSO_PID
   Onze essais, comparaison au banc. Six a dix minutes.
6. MATLAB : Construction_PSO_PID_Trois_Modeles
   Tes trois modeles de base -> PSO_PID_Control.slx,
   PSO_PID_Control_control_disturbance.slx, PSO_PID_Control_load_disturbance.slx
   (seuls P, I, D changent ; auto-test de 20 ms par modele, 0.05 V au plus).
7. python verifier_modeles_pso_pid_trois.py
   Fin attendue : "RESULTAT : les trois modeles sont conformes."
8. MATLAB : Simuler_PSO_PID_Trois_Modeles
   Nominal, F1, F2 compares a S1, S2, S3 du banc ; une figure par modele.

Envoie-moi la sortie console des etapes 3 a 8. Si une etape s'arrete sur
une erreur, envoie-la telle quelle sans passer a la suivante.
Aucun script MATLAB n'a pu etre execute ici (pas de MATLAB) ; les
verificateurs Python ont ete testes sur des modeles fabriques (conformes et
faux).

CE QUE L'ETAPE 5 DOIT DONNER (banc)
-----------------------------------
- Gains : P = 0.239585, I = 412.0556, D = 1.913247e-05, N = 64122.9.
- Tous les evenements reviennent dans la bande.
- S1 : depassement 7.1 % (ZN 14 %) ; S5 : IAE 2.46 mV.s (ZN 3.87) ;
  S8b : depassement 73.6 %.
- Cout J : PSO-PID 0.714 ; Ziegler-Nichols 1.000 ; meilleur PID fige sur
  grille 0.738. Rappel : ELM-PID 0.784, PINN-PID 0.684, Fuzzy-PID 0.877.
- Gains fixes : Simulink doit retrouver le banc a quelques dizaines de mV
  pres, comme le PID classique et le PID fige.

CE QU'IL FAUDRA ECRIRE DANS LE MEMOIRE (banc)
---------------------------------------------
- Le PSO-PID (J = 0.714) rejette mieux les perturbations que
  Ziegler-Nichols et que le meilleur PID fige (apres 30 ms : 0.672 contre
  1.000 et 0.710), avec un demarrage un peu plus lent que ce dernier (0.855
  contre 0.831).
- Il fait mieux que le "meilleur PID fige" sans avoir vu les onze essais :
  celui-ci est le meilleur point d'une grille de pas racine de 2, pas un
  plafond exact ; l'appeler "meilleur PID fige sur grille".
- Le PSO a atteint ce que peut donner un PID a gains fixes dans ces
  contraintes (cinq graines : J de 0.714 a 0.730) ; la limite restante est
  la structure (gains fixes, marge de 30 degres active a 98 ohms).
- Limite a dire : les essais de reglage reprennent les familles de
  perturbations de la specification, sur d'autres points de fonctionnement.
