LA METHODE EN BREF
- Loi PID incrementale de Lu ; toutes les 0.5 ms, si l'erreur efficace de
  la fenetre depasse 0.1 V, 5 iterations d'Adam sur les gains, avec un cout
  predictif sur 110 pas calcule avec le PINN depuis l'etat estime par un
  filtre de Kalman etendu.
- M1 : les gains sont projetes sur l'ensemble admissible lui-meme (meme
  critere que la boite d'origine : marge nominale >= celle du depart,
  coupure <= fs/10), et non plus sur une boite dont le depart etait un coin
  (Goodwin et Sin 1984 ; Ioannou et Sun 1996).
- M2 : projection au point admissible le plus proche, avec restauration
  vers la frontiere (Rosen 1961), le meme code que l'ELM-PID.

CE QUE SIMULINK DOIT DONNER (banc)
----------------------------------
- Les gains changent sur les trois cas de base (S1 7 fenetres, S2 13, S3
  13) ; Ki monte jusqu'a 1.64 x ZN sur S8a et S8b ; Kd finit sous 1 x ZN
  sur les cas de base.
- Tous les evenements reviennent dans la bande.
- Cout J : PINN-PID 0.692 ; version de depart (boite) 0.684 ; R0 0.917 ;
  Ziegler-Nichols 1.000 ; meilleur PID fige sur grille 0.738.
- Chaque decision d'adaptation depend d'un seuil de 0.1 V : si un ecart de
  quelques mV en fait basculer une, les gains suivent ensuite un autre
  chemin. La validation du bloc est l'etape 1.

CE QU'IL FAUDRA ECRIRE DANS LE MEMOIRE (banc)
---------------------------------------------
- La correction de la boite libere les gains mais ne change pas J de facon
  mesurable (0.692 contre 0.684, moins que l'effet de L ou C a +-0.1 %).
- La meme loi avec les gains trouves sur S8b, figes, fait mieux (0.652)
  que le PINN-PID adaptatif : la methode sert surtout a trouver de bons
  gains ; les faire varier en ligne n'ajoute rien ici.
- La precision du predicteur compte peu (modele physique faux : 0.694 a
  0.730) : le resultat vient de la boucle d'adaptation, pas du reseau.
